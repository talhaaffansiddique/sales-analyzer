11 How "add more files, software sorts accordingly" works

1. Detect — match by sheet names (Sales Detail + expected columns). Recognised → parse the tidy sheet directly. Unrecognised → fall back to the wide-report parser or the CSV template.
2. Normalize — trim whitespace; map Customer→company; keep Product Code as the SKU key; backfill blank formulations from the Formulations sheet.
3. Merge & dedupe — upsert on (Customer, Product Code | Product, Year). Newest file wins on conflict. Overlapping year ranges are fine.
4. Extend axes — a later 2022–2025 file just widens every year filter and chart automatically (already supported).
5. Source registry — every row remembers which file + upload date it came from; a "Data sources" panel lists files, row counts, year coverage, and partial-year flags, with per-file remove.
6. Re-flag partials — each file carries its own "thru <month>" marker so run-rate logic stays correct as data grows.
